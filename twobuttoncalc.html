Odrzywołek's Two-Button Scientific Calculator

This tool is based on Andrzej Odrzywołek's paper All elementary functions from a single operator

For further details on why this works you can check James Grime's video on Numberphile


This calculator uses just one function and one constant:

Function: eml (x, y) = exp (x) - ln (y)

Constant: 1

You don't even need an "=" button; as soon as the number of constants entered equals the number of functions plus one it will show the result.


Note: This calculator is implemented in JavaScript and is for educational purposes only; it might have rounding errors and show NaN for some values depending on how you compute certain functions

After each example a set of buttons are provided to enter each part of the expression automatically, so that you can test them without having to enter the whole expressions manually.
Constants will have 1 button; functions with 1 parameter will have two buttons splitting the expression around the parameter; and three buttons for functions requiring two parameters.
